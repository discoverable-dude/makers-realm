## Free alternatives
Unsplash, Pexels and Pixabay have free licences that allow commercial use without credit. This session cannot reach them, so someone would need to pick and download the images.

## Before using any stock photo
- Check the licence covers commercial web use and that you can use it on a shop.
- Avoid images with identifiable children or recognisable branded products.
- Add alt text when you upload.
